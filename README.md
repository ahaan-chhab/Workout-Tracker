# WorkoutTracker

## Project Goal
FitTrack is a Java workout tracker that allows users to log exercises, sets, reps, and weights. It saves workout history and helps users track their strength progress over time.

## MVP Features
- Log exercises, sets, reps, and weights.
- Save workout information to a file.
- View previous workout history.
- Track exercise progress over time.

## Future Plans
- Display progress graphs.
- Create custom workout routines.
- Track personal records for each exercise.

## Tech Stack
- **Language:** Java
- **Libraries:** Scanner, File, FileWriter, and ArrayList.
- **Tools:** Git and GitHub.
- **Data Storage:** CSV or text files.
- **Interface:** Command-line menu.
- **External Data:** None.

## Project Structure
- `src/` - Java source code.
- `tests/` - Project testing.
- `docs/` - Project planning documents and diagrams.
